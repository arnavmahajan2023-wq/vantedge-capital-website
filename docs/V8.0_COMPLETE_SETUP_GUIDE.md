# VANTEDGE v8.0 — Complete Setup Guide

1. Upload this package to the GitHub repository and push main.
2. Cloudflare deploys using `npx wrangler deploy`.
3. Rotate the exposed Turnstile secret.
4. Create a free Resend account.
5. Add and verify `send.vantedgecapital.in`.
6. Keep Resend receiving/inbound disabled.
7. Do not change Zoho MX records for the root domain.
8. Create a Resend API key named `VANTEDGE Website Production`.
9. In Cloudflare Worker Variables and Secrets add:
   - TURNSTILE_SECRET (Secret)
   - RESEND_API_KEY (Secret)
10. Click Deploy after saving secrets.
11. Authorise all website hostnames in Turnstile.
12. Test the Contact page and check Zoho Inbox, Spam, Resend Logs, and Worker Logs.

Error meanings:
- Service temporarily unavailable: a required secret is missing.
- Security verification failed: Turnstile key/hostname mismatch or expired token.
- Email authentication not configured: Resend key invalid or missing.
- Email delivery could not be completed: Resend domain/sender not ready.
- Green success: Resend accepted the email.
