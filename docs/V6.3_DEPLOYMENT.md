# VANTEDGE Website v6.3 — Stable Cloudflare Production

This release replaces the previous Turnstile token detection with an explicit,
callback-based verification flow.

## Deployment settings

- Project name: `vantedge-capital-production`
- Build command: leave blank
- Deploy command: `npx wrangler deploy`

## Required Cloudflare Worker secrets

- `TURNSTILE_SECRET`
- `CF_ACCOUNT_ID`
- `CF_EMAIL_API_TOKEN`

The public Turnstile site key is already configured in:

`public/assets/js/settings.js`

## Improvements

- Uses normal Turnstile size instead of flexible mode
- Captures verification token explicitly
- Submit button stays disabled until verification succeeds
- Handles expired, timed-out and failed challenges
- Provides clear user-facing status messages
- Keeps the secure server-side Turnstile validation
