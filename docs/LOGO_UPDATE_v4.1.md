# VANTEDGE Website v4.1 — Approved Logo Correction

This release replaces the temporary placeholder logo with the approved VANTEDGE CAPITAL gold-and-navy corporate identity.

## GitHub Desktop update
1. Extract this ZIP.
2. Open GitHub Desktop and select `vantedge-capital-website`.
3. Click **Show in Explorer**.
4. Copy all files and folders from this extracted v4.1 package into the repository folder.
5. Choose **Replace files in the destination**.
6. Return to GitHub Desktop.
7. Commit summary: `Correct VANTEDGE approved logo`
8. Click **Commit to main**.
9. Click **Push origin**.
10. Wait 1–3 minutes and hard-refresh the live website with **Ctrl + Shift + R**.

No GitHub Pages or domain settings need to be changed.
